# RamenDataset

1. Запуск

Открыть `ramen_index_landing.html` и посмотреть страничку в браузере

2. Настройка и правки

`ramen_index_landing.html` - лендинг
`styles/main.css` - стили для лендинга
`images/` - сюда сохраняются графики и есть предзаготовленный скриншот 01_cleaning.png
`datasets/` - оригинальный датасет и его очищенная версия
`Ramens.ipynb` - открывается в jupyter notebook, скрипт, который анализирует и очищает датасет, а также генерирует картинки графиков
